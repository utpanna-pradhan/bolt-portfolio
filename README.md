  # 🚀 Personal Portfolio Website

This is a responsive, modern personal portfolio website generated using **Bolt AI** and deployed with **Netlify**. 
It showcases  skills, projects,expereince,blog,chatbot and contact information in a clean and interactive format.


# ✨ Features
Fully responsive and mobile-friendly

Clean UI with modern design

Sections: Home, Experience,work,blog,toggle,chatbot, Contact

Social media links 

Fast loading and SEO optimized

# 🚀 Getting Started
 Clone the repository:

 git clone https://github.com/utpanna-pradhan/bolt-portfolio
 
 cd bolt-portfolio

run on local:

npm install

npm run dev
